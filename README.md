The goal of this project is to develop a face-recognition system on video/CCTV / live-camera feed that can identify pre-registered individuals (e.g. students) using precomputed embeddings, and respond to voice commands (“find/locate X”) to locate a given identity in real time.

System Overview :

The project maintains a custom dataset of face images (organized via a CSV listing, generated by a dataset-creation notebook). 
GitHub

From this dataset, the project computes face embeddings using a chosen face-recognition model, storing them in a .pkl embedding database. 
GitHub

During runtime, the system matches incoming video frames (recorded feed or webcam/live feed) against the stored embeddings to recognize a face and map it to a known ID. 
GitHub

A voice-to-text module enables a command interface: users can ask “locate 24” (or similar), and the system will then attempt to detect and identify that specific person in the live/recorded video stream. 
GitHub

Key Components & Workflow :

Dataset Creation — via a notebook that converts raw images into a standardized dataset list. 
GitHub

Embedding Generation — a notebook that processes the dataset to produce embeddings for each individual, stored in embeddings.pkl. 
GitHub

Matching Module — code (scripts) that take video frames (webcam, CCTV feed, or recorded video) and match detected faces against the embedding database. 
GitHub

Voice-Command Interface — a script/module (speechrec.py) translating voice input to text commands, enabling dynamic querying of the system for a particular identity. 
GitHub

Intended Use & Advantages :

Designed to operate on live or recorded video feeds (CCTV, webcam, etc.), making it suitable for surveillance, attendance tracking, or security monitoring.

Because embeddings are precomputed and matching can be fast, the system aims to provide near real-time face recognition.

The use of a custom dataset (and potential image augmentation / quality degradation — based on your earlier plan) helps adapt the system to realistic CCTV scenarios (low resolution, variable lighting, noise).

The voice-command interface adds a user-friendly, interactive control layer, letting operators quickly query for individuals without manually scanning video feeds.

Limitations & Assumptions (for clarity in research/paper context)

The repository’s README mentions that the dataset was created “temporarily in small scale by using random images from the internet,” rather than a formal, controlled dataset. 
GitHub

Therefore, results and claims should be interpreted accordingly — this is more of a proof-of-concept / prototype rather than a polished, large-scale deployment.

As the dataset quality, identity coverage, and embedding robustness depend heavily on input data, performance in real-world CCTV environments remains to be validated thoroughly.
