Details about files : 
i) Embeddings.ipynb -- Notebook which generates the embeddings of the images from the dataset .
ii) Matching.ipynb -- contains Saved code for the matching parts (not to be used) . 
iii) Matching_cctv.ipynb -- Matching using cctv feed .
iv) dataset.csv -- Dataset used for embedding generation .
v) dataset_creation.ipynb -- Makes the dataset.csv from the raw images.
vi) embeddings.pkl -- Stores the embeddings of the images .
vii) match_webcam.py -- Matching via webcam .
viii) match_recrded.py -- Matching via recorded feed . 
ix) speechrec.py -- Speech(voice) to text command generation script. 
x) test -- Images .
xi) combined.py -- cctv matching.


DISCLAIMERS :
i) Dataset is made temporarily in small scale by using random images from the internet .
